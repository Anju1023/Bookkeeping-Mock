## 採点・保存・JSON

第1問は1仕訳の完全正解で3点。行順は自由で、同じ側の同一科目の重複や不要行の入力は不正解。第2問は10採点単位×2点、第3問は11採点単位×3点＋1採点単位×2点。複数欄を一単位とする箇所は全欄の正解が必要。採点後の解説に各単位と配点を表示する。

空欄と0は区別し、不正な金額を0として採点しない。全角数字に対応し、Enterとフォーカス移動で金額を整形する。精算表の不要側を入力する問題では、空欄にする指定に対して0を入れた場合も不正解。

保存キーは `boki3-mock-2026-02-v2`。旧版・他の回の保存内容は読み込まず、削除もしない。タイマーは絶対期限で管理し、再読み込み中も時間は進む。保存禁止の環境でも試験を続行できる。

採点後の明示操作で `boki3-2026-02-v2-answers-<日時>.json` を保存できる。`schemaVersion: 2` で、模試ID・版、受験日時、得点、問題文、証ひょう・帳簿等の全資料、本人の入力文字列と数値、正解、採点単位ごとの得点、解説を含む。金額の空欄・不正値は数値が `null`。`blank` 型の正解 `null` は空欄指定、表の `{{id}}` は同じIDの解答欄を指す。復元した結果と時間切れ後も保存可能。自動送信とJSON再取込は行わない。
