# 第2回 日商簿記3級 ネット試験模試（2026年度）

`index.html` を直接ブラウザーで開くか、一覧から第2回を選ぶ。インストール・サーバー・ネット接続は不要。

60分・全3問・100点満点・合格目安70点。第1問は仕訳15問45点、第2問は勘定記入と商品有高帳20点、第3問は決算整理と財務諸表35点。電卓と計算用紙を用意し、20分・15分・20分を目安に解き、残り5分で見直す。

## 出題方針と公式情報

確認日：2026年10月30日。2026年度（2026年4月1日～2027年3月31日）の範囲に対応する非公式のオリジナル模試。問題文・金額・正解・解説は独自作成で、公式問題の転載ではない。

公式サンプル5（2026年4月追加）では、利息に関する勘定記入、固定資産台帳、未処理事項を含む財務諸表が公開されている。サンプル3には家賃の経過勘定、サンプル1には商品有高帳もある。最新例だけに偏らず、公開例に見られる「資料から取引を読み取り、勘定・帳簿・決算へつなげる」形式を参考にした。これは学習上の出題方針であり、本試験の出題頻度の統計や出題予告ではない。

- 第1問：返品、売上諸掛、電子記録債権、手形、当座借越、立替金、仮受金、切手、償却債権取立益、期中売却の月割償却、敷金、消費税、社会保険料、配当金支払い、損益振替。単純な暗記だけでなく負債・費用の区別や処理時点を確認する。
- 第2問（1）：前受家賃の決算整理・締切り・翌期首の再振替。公式例の文章や数値は用いず、収益側の経過勘定で構成する。
- 第2問（2）：先入先出法の商品有高帳。異なる原価の在庫層をまたぐ2回の払出し、数量・金額の繰越、商品売買益を求める。公開例の移動平均法をそのまま流用せず、区分表内の別の評価方法を練習する。
- 第3問：誤記訂正、未記帳の売掛金回収、仮払金からの備品振替を先に処理し、貸倒引当金・月割償却・前払保険料・未払費用・法人税等を集計する。整理前残高をそのまま使う誤りを確認できる。

2027年4月1日からの範囲・配点改定（45・25・30点）には対応しない。本模試は従来の45・20・35点で構成する。本試験の非公開採点基準や画面を完全に再現したものではない。

## 機能・採点・保存

金額の全角入力・桁区切り、大問移動、見直しマーク、絶対期限の60分タイマー、自動保存、復元、期限切れ自動提出、全問解説、提出後の入力ロック、再挑戦に対応。自動保存できなくても受験を続けられる。

仕訳は各問完全正解3点、行順は自由。同一側の同一科目の重複は不可。未使用行は科目・金額とも空欄とする。第2問は各欄2点、第3問は各欄2～3点、合計35点。空欄・不正な金額をゼロとして採点しない。採点は本模試独自。

保存キーは `boki3-mock-2026-02-v1`。第1回とは分離する。採点後の「解答をJSONで保存」から `boki3-2026-02-answers-<提出日時>.json` を明示的にダウンロードできる。問題・必要資料・入力文字列と数値・正解・得点・解説・日時を含み、ファイル単体で復習できる。自動送信はしない。
