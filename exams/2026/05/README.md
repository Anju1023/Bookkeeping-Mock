## 出題方針

2026年11月6日作成。プロジェクトREADME、第1～4回のREADME、[全7回の比較台帳](../../../docs/模試全7回_出題比較_2026-11-02.md)、[難易度比較](../../../docs/難易度比較調査_2026-11-02.md)を読み、今回確認した公式公開例を踏まえて新規作問した。既存回の数値置換や公式問題の転載ではない。

- 第1問45点：仕訳15問。売上集計表とカード決済、売上返品の税抜処理、敷金返還、前期貸倒債権回収、現金過不足の原因判明、4費用の精算など。基本問題と複合問題を混在させ、論点名は提出後のみ表示する。
- 第2問20点：前期から継続する貸付けと当期の新規貸付けについて、再振替・見越し・損益振替・翌期開始記入を連絡する。別小問は得意先別元帳から売上・回収・期末残高を逆算し、総勘定元帳と照合する。
- 第3問35点：決算整理後残高試算表。手数料控除後の債権回収、前期債権貸倒れ、未記帳掛売上をすべて引当金計算に反映する。仮払金で処理した備品の振替と月割償却、経過勘定、消費税・法人税を整理する。決算振替前なので利益剰余金に純利益を加算しない。

目安は第1問20分・第2問15分・第3問20分・見直し5分。初見受験者の得点・所要時間による難易度測定は未実施。本試験や他社との難易度の同等性は保証しない。

## 採点・保存・JSON

第1問は1仕訳の完全正解で3点。借方・貸方それぞれの行順は自由、同一側の同一科目の重複は不正解。第2問は10単位×2点、第3問は11単位×3点＋1単位×2点。複数欄の採点単位は全欄正解が必要。採点単位と配点は提出後に表示する。

金額は全角入力、Enter・フォーカス移動での桁区切りに対応する。仮払金ゼロは明示的に0を入力し、空欄・不正値と区別する。「？」の計算用欄は入力・保存できるが採点対象外。

保存キーは `boki3-mock-2026-05-v1`、履歴は `boki3-mock-2026-05-v1-history-v1`。ほかの回・版の保存領域は読み書き・削除しない。絶対期限タイマー、再読込復元、時間切れ提出、提出後ロック、保存不能環境での受験に対応。

提出後の明示操作で `boki3-2026-05-v1-answers-<日時>.json` を保存できる。JSON形式は `schemaVersion: 2`。模試ID・版・受験日時・得点・問題文・全資料・本人の入力・正解・採点単位の得点と解説を含む。金額は入力文字列と数値を保持し、空欄・不正値の数値は `null`。表の `{{id}}` は同じIDの解答欄を示す。結果復元・時間切れ後も保存可能。自動送信・JSON再取込は行わない。
