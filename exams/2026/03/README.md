# 第3回 日商簿記3級 ネット試験模試（2026年度）

[index.html](index.html) をブラウザーで直接開いて受験する。60分・100点満点・合格目安70点。対象は2026年度（2027年3月31日までの受験）。非公式のオリジナル問題で、採点基準は本模試独自。

## 調査と出題方針

確認日：2026年11月2日。

公式サンプルの掲載ページではサンプル1～5を公開しており、最新の追加は2026年4月のサンプル5。サンプル5の第1問・第2問の両小問・第3問を読み、2026年度の区分表と照合した。公式サンプルは形式を知るための資料で、ネット試験の出題頻度を示す統計ではない。受験者ごとに問題が異なるため、「直近の本試験で必ず出る」といった予告はできない。

公開例からは、単独の仕訳だけでなく、期間計算と勘定の締切り、固定資産台帳の読解、未処理取引を反映してから決算整理する練習が必要と判断した。この判断を問題構成へ反映したもので、公式問題の文章・金額は転載していない。

| 大問  | 内容                                                                                                                                       | 配点 | 時間の目安 |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------ | ---- | ---------- |
| 第1問 | 仕入諸掛・返品・電子記録債務・手形・貸付利息・仮払精算・前受金・現金過不足・貸倒れ・取得原価・未払金・消費税・給与・増資・収益締切りの15問 | 45点 | 20分       |
| 第2問 | 前受家賃の決算整理・締切り・再振替、固定資産台帳から定額法償却・帳簿価額・売却益を計算                                                     | 20点 | 15分       |
| 第3問 | 誤記訂正・未記帳入金・仮払金精算後の貸倒引当金、棚卸、月割償却、経過勘定、法人税等、財務諸表                                               | 35点 | 20分       |

残り5分は見直し。第2問前半は第2回と共通の経過勘定問題、第3問は第2回と同じ決算構成で金額を変更した練習セット。第1問と固定資産台帳は新規作成した。完全に異なる論点だけで構成した回ではない。

2027年4月1日以降は出題範囲と配点が変わる。本模試は改定後の45・25・30点に対応せず、2026年度の45・20・35点で作成した。手形も2026年度の範囲として扱っている。

## 操作と採点

全角数字、Enter・フォーカス移動での金額整形、自動保存・復元、大問移動、見直し、60分の絶対期限、時間切れ自動提出、解説、提出後ロックに対応。仕訳は行順自由・同じ側の科目重複不可で完全正解3点。第2問は各欄2点、第3問は各欄2～3点。空欄・不正値はゼロ扱いしない。

保存キーは `boki3-mock-2026-03-v1`。復習用JSONには模試ID `boki3-2026-03`、日時・得点・問題・資料・入力文字列と数値・正解・解説を含む。採点後の明示操作でローカルに保存し、自動送信しない。保存不可でも受験を継続できる。

## 検証

Tailwind CSS 4.2.4でCSSを埋め込み、オフライン利用を維持。第3回専用のjsdom検証で全角・金額整形、空欄・不正値、保存復元、保存キー分離、大問移動、正答100点、誤答、行順・重複、入力ロック、自動提出、JSON資料・ダウンロードを確認した。

問題データと別計算で全仕訳の貸借一致、整理前試算表の貸借各17,220,000円、当期純利益757,200円、決算後の貸借各6,773,200円を確認。固定資産台帳はAの当期償却120,000円・期末累計360,000円、Bの償却45,000円・帳簿価額315,000円、Aの仮定売却益30,000円を検算した。

Chromeの1440×1000画面で開始前ページを表示確認した。試験中・採点後の画面操作はjsdomで検証しており、実ブラウザーでの手動操作とスマートフォン表示は未確認。


## ネット試験の解答画面についての再調査・修正

確認日：2026年11月2日。紙の公式サンプルは出題内容・帳票の構造を確かめる資料であり、ネット試験の画面そのものを示す根拠とは区別する。

- [日本商工会議所のネット試験案内](https://www.kentei.ne.jp/33013)：3級は選択式＋入力式・60分。仕訳の科目はプルダウン、金額や勘定科目名を入力する問題もある。大問の切替操作と、金額に円記号等を含めないことを確認した。
- [PDCA会計が提供するネット試験模試](https://www.pdca-accounting.com/bokinyuumon/netshiken-mogi01-level3.php)：公開された画面構造を確認。第2問の勘定表にプルダウンと金額入力、第3問の貸借対照表・損益計算書に表内の金額・語句入力が配置されている。これは提供元の一次資料として確認した他社模試の実装であり、本試験画面の完全な証明や出題頻度の統計としては扱わない。
- [TAC出版のネット試験対策案内](https://bookstore.tac-school.co.jp/pages/add/lp/boki_kaitei)：ブラウザーで操作する模擬試験プログラムと操作案内の提供を確認。有料書籍用プログラムの試験画面は未確認。
- [ネットスクールのネット模擬試験案内](https://nsboki-cbt.net-school.co.jp/index_c)：PC画面を読みマウス・キーボードで解答する練習として提供されている。利用にはメール登録・アンケート・案内メールへの同意が必要であり、登録して試験画面を確認したものではない。

この確認に基づき、第3回の第2問を「勘定表・固定資産台帳の中で解答」、第3問を「左右に借方・貸方を配置した財務諸表の中で解答」へ変更した。入力欄を別の一覧に切り離さない。問題・正解・配点・解答IDは同じため、保存キーv1を維持して解答を引き継ぐ。表内の「？」は入力不要の採点対象外欄。控除後の資産額を答える指定は本模試固有の簡略化として維持しており、本試験画面の完全再現とはしていない。

専用検証で全24欄の表内配置、解答IDの一意性、左右の科目配置を追加確認。既存の採点・保存復元・JSONの検証も通過。今回の変更で精算表の問題は追加していない。第1回・第2回の画面は変更していない。
