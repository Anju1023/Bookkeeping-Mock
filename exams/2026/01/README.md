# 第1回 日商簿記3級 ネット試験模試（2026年度）

`index.html` をブラウザーで開いて「模試をはじめる」を押すと開始する。インストール・サーバー・ネット接続は不要。Tailwind CSS の生成済みスタイルと JavaScript は HTML に内蔵している。

- 60分、全3問、100点満点。仕訳15問45点、勘定記入・固定資産台帳20点、決算整理・財務諸表35点。
- 金額は Enter またはフォーカス移動で `#,##0` に整形する。全角数字にも対応。空欄とゼロは区別し、小数・負数・文字はエラー表示する。
- 大問移動、仕訳の見直しマーク、自動保存、時間切れの自動提出、採点、全問の正解・解説、同じ問題の再受験に対応。
- 保存先はブラウザーの localStorage。同じブラウザー・同じファイルの場所で再開する。再読み込み中も時間は経過する。保存が禁止された環境では画面を閉じずに利用する。

## 解答のJSON保存

採点後の結果画面で「解答をJSONで保存」を押すと、`boki3-2026-01-answers-<提出日時>.json` をダウンロードできる。採点結果を再表示した場合や時間切れの自動提出後にも利用可能。問題文・資料・あんじゅの解答・正解・得点・解説を含み、このファイルをぴぃこに渡して復習できる。外部への自動送信やJSONからの再取込は行わない。

## 出題方針

2026年10月30日に日本商工会議所の公式情報を確認。2026年度の範囲で作成した非公式オリジナル模試で、2027年3月31日までの受験を想定する。

2026年4月追加の公式サンプルの構成を参考に、利息の経過勘定、固定資産台帳、未処理・決算整理から財務諸表への集計を重点にした。公開例からの学習上の判断であり、実際の出題頻度の統計や出題予告ではない。問題文・金額は独自作成で、公式問題は転載していない。仕訳は日常取引から税金・株式会社会計までを横断する。

2027年4月1日からは範囲と配点が改定され、配点は45・25・30点となる。このHTMLは2027年度版には対応していない。

本試験の金額入力は数字のみ・カンマ不要。本模試は指定に合わせ、Enterで桁区切り表示する。

採点は本模試独自。仕訳は各問完全正解3点で、同一側の同じ科目の重複や不要行への入力は不正解とする。行順は自由。第2問は各空欄2点、第3問は欄ごとに表示した2～3点。実際の非公開採点基準を再現するものではない。

## 保守・検証

以下のコマンドはプロジェクトルートで実行する。

生成CSSは Tailwind CSS 4.2.4。変更後はローカルにある同パッケージのディレクトリを指定して再生成できる。

```bash
node scripts/build-css.mjs /path/to/node_modules/tailwindcss exams/2026/01/index.html
```

機能検証には jsdom 29 を使用した。jsdom のパスは環境変数でも指定できる。

```bash
JSDOM_PATH=/path/to/node_modules/jsdom node scripts/verify.mjs tests/exams/2026/01.test.mjs
```

金額整形、大問移動、保存復元、正答100点・誤答・重複科目、提出後ロック、期限切れ自動提出をDOM上で確認。試算表の貸借一致、当期純利益378,400円、決算後の貸借合計3,238,400円も別計算で検算した。

この実行環境では Chrome の起動がサンドボックス制約で失敗したため、実ブラウザーの描画確認は未実施。jsdomはTailwindの一部の新しいCSS構文を解釈できないため、機能検証ではスタイルを除外している。
