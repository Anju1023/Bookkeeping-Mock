# 簿記の時間

日商簿記3級のネット試験を練習する、非公式のオリジナルHTML模試集。

ルートの [index.html](index.html) をブラウザーで開き、模試を選んで開始する。インストール・サーバー・ネット接続は不要。各模試のHTMLを直接開いても利用できる。

## 学習ページ

[勘定科目と仕訳のルール帳](study/index.html) で、5分類・増減・普段の仕訳・決算・覚え方を確認できる。科目名や説明の検索、分類での絞り込み、答えを開ける理解チェック付き。模試一覧からも開けて、HTML単体でオフライン利用できる。参考資料と確認日はページ末尾に記載。

## ディレクトリ構成

```text
index.html                       模試一覧
study/index.html                 勘定科目と仕訳のルール帳
exams/<年度>/<回番号>/index.html   各回の模試（単体で利用可能）
exams/<年度>/<回番号>/README.md    各回の出題方針・参考資料
scripts/build-css.mjs             Tailwind CSSの生成・埋め込み
scripts/verify.mjs                各回の検証を実行
tests/exams/<年度>/<回番号>.test.mjs 各回の機能・計算検証
AGENTS.md                        作業ルール・模試追加手順
```

年度は試験範囲の適用年度、回番号は `01`、`02` のような2桁で管理する。今後は `exams/2026/02/` などに追加し、入口の一覧にも掲載する。

## 共通の機能

- 金額は Enter またはフォーカス移動で `#,##0` に整形。全角数字にも対応。
- 60分タイマー、大問移動、見直しマーク、ブラウザー内の自動保存。
- 時間切れの自動提出、採点、全問の正解・解説、同じ問題への再挑戦。
- 採点後の「解答をJSONで保存」で復習用ファイルをダウンロード。問題文・資料・解答・正解・得点・解説を含む。
- 問題・配点・対応年度は各回の案内を確認する。

## JSONを使った復習

採点後に「解答をJSONで保存」を押し、保存した `.json` ファイルをぴぃこに渡して「間違えた問題を解説して」と伝える。JSONには模試の年度・回・版、受験日時、解答時間、得点、各問の問題文・資料・入力内容・正解・解説、仕訳の見直しマークが含まれる。自動送信は行わず、ダウンロードするだけ。

金額は計算用の数値と入力文字列の両方を記録する。空欄や不正な金額の数値は `null` とし、入力文字列で区別できる。思考過程そのものは記録していない。JSONは復習用で、アプリへの再取込には対応していない。

## 開発・検証

追加手順や守るべき動作は [AGENTS.md](AGENTS.md) を参照。以下はプロジェクトルートから実行する。

```bash
# 全HTMLのCSSを再生成（Tailwind CSS 4.2.4）
node scripts/build-css.mjs /path/to/node_modules/tailwindcss

# 特定のHTMLのみ再生成
node scripts/build-css.mjs /path/to/node_modules/tailwindcss exams/2026/01/index.html

# 全回を検証（jsdom 29）
JSDOM_PATH=/path/to/node_modules/jsdom node scripts/verify.mjs

# 特定の回のみ検証
JSDOM_PATH=/path/to/node_modules/jsdom node scripts/verify.mjs tests/exams/2026/01.test.mjs
```

CSSはHTMLに埋め込むため、配布時に依存パッケージは不要。検証ファイルは `tests/exams/` 以下の `.test.mjs` を自動収集する。各回に専用の検証を追加すれば、全回実行の対象になる。
